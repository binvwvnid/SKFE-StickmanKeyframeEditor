# 画布网格叠加（代码型插件示例）

一个**代码型**插件示例：在 SKFE「画布」分区底部加一个「开启网格叠加」按钮，开启后画布上叠加一层**线网格**（与 SKFE 自带的点阵网格不同），可调间距与颜色。网格只在编辑时可见，**不影响任何导出**。

它演示了三个关键技巧：
1. 在已有工具分区底部追加自定义控件；
2. 用 `SKFE.core.eventBus.EventBus.on('need:render')` 在主程序渲染后补画（监听注册更晚，所以排在后面执行）；
3. 因为 EventBus **没有 `off`**，禁用时用标志位让回调停止工作——这是官方推荐做法。

---

## 一、直接导入（现成 zip）

作者工具包内的 `canvas-grid.zip` 已打包好，可直接导入（从插件面板「一键下载全部（ZIP）」拿到工具包，或由插件作者私下分享给你）：

1. 打开 SKFE → 底部栏「**插件**」分区。
2. 点「**导入插件**」，选 `canvas-grid.zip`。
3. 读风险提示，确认导入（代码型插件拥有与主程序同级权限，只导入信任的文件）。
4. 切到「**画布**」分区，拉到底部，点「开启网格叠加」。

> 自查：打开 zip 第一眼应直接看到 `manifest.json` 和 `index.js`，**不能先看到一层文件夹**。如果在文件夹上右键压缩会多套一层，导致「缺少 manifest.json」。

---

## 二、自己打包

1. 进入 `canvas-grid` 文件夹（**不要**在文件夹上右键压缩）。
2. 选中里面三个文件 `manifest.json`、`index.js`、`README.md`。
3. 右键 → 压缩为 ZIP，命名任意，例如 `canvas-grid.zip`。
4. 确认 zip 根目录直接是这三个文件。
5. 按上面「直接导入」的步骤导入。

改 `index.js` 就能改功能；改完重新打包、重新导入（同 id 视为升级，保留启用状态，导入后刷新页面）。

## 三、数据说明

- 设置存在本机浏览器 `localStorage` 的 `skfe_plugin_canvas_grid_v1`，不写入作品文件。
- 禁用 / 删除插件后刷新页面，按钮与网格会一起消失。
- `skfeVersion: ">=7.7.0"` 只做提示，版本不符仍可导入。
