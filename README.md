## 1. 快速开始

### 1.1 在哪使用

- **网页版**：打开网页地址即可使用，数据默认保存在当前浏览器里。
- **Windows / 安卓安装包**：从 Releases 页面下载对应安装包。安卓版与网页版共用同一套编辑器界面。

### 1.2 界面总览

- **画布**：屏幕中央的主要创作区域，用来摆放火柴人、图片、视频、形状等元件。
- **底部栏 / 侧边栏**：包含属性、元件、画笔、画布、高级、项目、导出、主题、插件等入口。点一个入口展开对应面板，再点一次同一个入口可全部收起。
- **时间轴**：点击右下角的帧动画面板进入，用来制作逐帧 / 关键帧动画。
- **轨道按钮**：在时间轴控制栏点 `🎞 轨道`，可把帧块视图切换成类视频剪辑软件的多轨视图。
- **撤销 / 恢复**：右上角提供撤销和恢复。

### 1.3 工程保存位置

- 工程里的图片、视频、音频等媒体会随 `.json` 一起保存。
- 编辑器会在浏览器 / App 内部做自动存档，刷新页面不会立刻丢工程。
- 项目库保存在当前浏览器 / App 本地，不会自动同步到另一台设备。

## 2. 画布、面板与基础操作

### 2.1 视角控制

- **电脑**：滚轮缩放；按住鼠标拖动空白处平移视角。
- **手机 / 平板**：双指捏合缩放；双指拖动平移视角。
- **边界保护**：画布缩放时至少保留 5% 在屏幕内，避免把画布完全拖出屏幕。
- **固定视图**：开启画布边界并固定视图后，不再修改画布的 XY 坐标，防止误触导致画面跑位。

### 2.2 面板操作

- 拖动面板顶部横条可以移动面板。
- 开启自由缩放后，可以拖面板右下角调整面板大小；浏览器会记住该开关状态。
- 可以锁定面板位置，避免误触拖动。
- 属性、元件、更多设置等区域采用通栏标题条；右侧滚动条较细，内容不会被滑块遮挡。
- 元件列表按当前帧的图层顺序从上到下显示；拖动行可调整顺序，并写入当前帧图层。开启全局属性修改时，排序会同步到该元件的所有帧。
- 全局属性修改右侧的「使用说明」会打开一个覆盖全屏的可关闭浮窗，内容就是当前 README 全文。
- 高级设置可开启「元件独立悬浮条」，把当前横向元件条移到独立浮窗；可拖动位置、横向拉宽，开关、位置与宽度都会记入缓存。自定义按钮悬浮条同样支持，右端缩放把手默认隐藏，鼠标悬浮或点击浮条时显示。

### 2.3 画布设置

- 可调整编辑时的背景、网格、地面参考线。这些只影响编辑视图，不影响导出画面。
- 可开启画布边界，设置导出比例，例如 1:1、9:16、16:9。
- 开启画布边界后，导出只保留画布框内的内容。

### 2.4 主题设置

- 可调整面板背景、按钮颜色、文字颜色等。
- 支持把当前配色保存为主题预设，方便在不同工程之间复用。

## 3. 添加与编辑元件

### 3.1 可添加的元件

在 `＋ 添加物体` 里可以添加：

- **火柴人**：主要创作对象，支持关节、比例、发光、IK、头型等完整动画功能。
- **图片 / 配饰**：导入本地图片作为道具或配饰，可绑定到火柴人关节上，也能单独设置位置、缩放、旋转、扭曲和关键帧。位图统一从这个入口导入。
- **导入视频**：真正可编辑的视频元件，可像图片一样调整大小、位置、旋转、透明度、四角扭曲与关键帧，也可以绑定到火柴人。它与「参考视频」不是同一种东西。
- **导入音频**：只承载声音的元件，接受音频文件和视频文件。把视频当音频导入即可当作「视频转音频」，但不做真实转码，也不生成真实采样波形。
- **对话框**：气泡文字，可设置文字、颜色、渐变、大小和尾巴方向。
- **摄像机**：按钮统一叫「摄像机」，按当前模式分流。2D 模式添加 2D 摄像机元件轨；3D 模式添加工程级 3D 摄像机虚拟轨。两者完全独立，互不显示、互不复用。摄像机自动铺满全轨道，不能分割、拉长、缩短或额外补帧；两颗关键帧之间自动补帧。
- **内置形状**：圆形、方形、三角形。

### 3.2 基础属性

选中元件后可以调整：

- **名称**：给元件重命名，方便在层级与轨道里分辨。
- **颜色 / 线条**：修改火柴人或形状的外观。
- **位置 X / Y**：可直接输入数字，也可用手柄在画布上拖动。
- **缩放 / 透明度**：快速调整大小和可见程度。
- **旋转**：支持超过 360° 的多圈旋转，也可调出手柄在画布上转。
- **水平镜像**：左右翻转。
- **层级**：`+1 层`、`-1 层`、`置顶`、`置底`。

### 3.3 火柴人专属属性

- **头型**：可在圆头、Vic、TCO、TDL、TSC 等头型之间切换。手绘头型跟随火柴人颜色、旋转、镜像与填充设置。
- **比例**：调节头部大小、手臂长度、腿长、躯干比例；可开启四肢独立、小手小脚、独立平移头部。
- **关节**：拖动画布上的蓝色关节点摆姿势，也可以用滑条精确旋转。
- **IK**：固定脚、手等关节后，移动躯干时肢体会自动适应固定点。
- **发光 / 阴影**：描边阴影、侧光、手部渐变、地面阴影、深色处理等都可按元件保存并参与关键帧。

### 3.4 视频元件

- **定位**：「导入视频」是可编辑元件；「导入参考视频」只是画布参照，不进元件列表、不参与导出、不可编辑。
- **默认长度**：视频导入后默认铺满当前工程总轨道长度，之后可在轨道中拖长、缩短、平移或分割。
- **播放范围**：只在当前轨道段落覆盖的帧区间播放画面和声音，播放头离开段落后停画静音。
- **连续播放**：段内连续播放，不被帧率反复拖拽，循环播放更平稳。
- **删除清理**：删除视频元件时，对应音源会一起释放，不会只剩声音。
- **导出**：视频元件参与实时画面与视频导出；静态帧 / 序列帧导出按当前帧处理。

### 3.5 音频元件

- **导入**：支持音频文件和视频文件；视频当音频用时只播放声音。
- **轨道位置**：音频不显示在元件列表里，在轨道中永远置底。
- **波形显示**：轨道长条显示确定性占位声波，不是真实采样波形。
- **属性限制**：音频只开放名称和音量，不提供位置、缩放、颜色、蒙版等画面属性。
- **播放规则**：与视频元件一样，只在自身轨道段落覆盖的帧区间出声，段外静音。
- **操作**：可在轨道中移动、拉长、缩短和分割；删除时音源同步释放。

### 3.6 3D 模式与双摄像机

- 3D 模式由底部栏 3D 面板顶部的总开关切换，点击底部栏面板本身不会自动切换模式。
- 2D 摄像机只出现在 2D 模式；3D 摄像机只出现在 3D 模式。元件列表与横向元件浮条都会按当前模式显示对应摄像机。
- 摄像机视角入口只放在右上角浮窗，图标旁只显示 `2D` 或 `3D`；未添加 2D 摄像机时不会显示 2D 入口。点击火柴人、关节点或 3D 移动锚点不会误切到摄像机视角。
- 2D 摄像机是真实元件轨；3D 摄像机是工程级虚拟轨 `__camera3d__`，承载 FOV、近远裁剪、正交高度、画幅宽高、位置、旋转、目标与偏移等参数。
- 自由观察视角和摄像机视角都可以打 3D 摄像机关键帧；关键帧之间自动补帧。摄像机轨不允许分割、拉长、缩短或插入 N 帧，只能调整曲线。
- 3D 导出逐帧读取摄像机轨，因此 PNG / JPG / GIF / MP4 / WebM 输出的是全轨道镜头运动，而不是导出瞬间的固定机位。尺寸按 3D 摄像机的 `width / height` 比例计算。
- 3D 观察视角中的关节点会随视角缩放，并相对火柴人保持合理比例；绑定元件会跟随父火柴人的三维位移与旋转，自身参数均为相对挂载点的值。

## 4. 火柴人进阶设置

### 4.1 比例与体形

- 可调头部大小、手臂长度、腿长、躯干比例。
- 开启四肢独立后，可分别设置左右手、左右腿长度。
- 伪透视（粗细变化）按肢体两端的粗细倍率制造深度感，不改变肢体实际长度。
- 小手小脚可单独设置手掌和脚掌占比。
- 独立平移头部可以制作歪头、头部偏移等姿势。

### 4.2 关节与 IK

- 蓝色圆点是关节点，直接拖动即可改变姿势。
- 关节旋转滑条用于精确调整角度。
- 开启关节拉伸后，拖动关节能同时改变肢体长度。
- 可隐藏关节点，方便截图或预览。
- IK 固定后，对应关节会保持原位，移动躯干时肢体自动伸缩。

### 4.3 发光与特效

- **描边阴影**：可设置颜色、不透明度、羽化、扩展和 XY 偏移，并可连同绑定配饰一起生效。
- **侧面高光**：增强立体感，可调粗细与方向。
- **手部渐变**：让手臂末端呈渐变色。
- **地面阴影**：每个火柴人独立设置，可单独打关键帧。
- **深色处理**：自动压暗后方肢体，增强空间层次。

### 4.4 画笔与橡皮擦

- 画笔笔迹作为矢量对象保存，可跟随物体移动、旋转和缩放。
- 橡皮擦只对当前选中的对象生效，擦除同样以矢量方式保存。
- 画笔 / 擦除 / 油漆桶三种模式严格互斥，开启其中一个会关闭另外两个。
- 画笔类型提供「默认」「柳叶笔」「蜡笔」三种，外观与配置均可保存。
- 支持直线模式与末端吸附，画完停在末端可自动吸附成标准图形。
- 移动端在画笔、擦除、油漆桶模式下都可双指缩放 / 平移画布；橡皮断触问题已修复。
- 支持撤销、清除本帧擦除、清除全部擦除；画布固定状态与固定时的视角会写入本地缓存。

## 5. 时间轴与关键帧动画

点击右下角 `帧动画面板` 打开时间轴。

### 5.1 基础帧操作

- `＋ 帧`：在当前帧后插入帧。
- `⧉ 复制帧`：复制当前帧。
- `🗑 删除帧`：删除当前帧。
- **多选**：勾选多选后可一次选择多个帧，支持批量补间、删除和导出。
- **拖拽排序**：按住帧块拖动即可调整顺序；触屏长按后可拖动。

### 5.2 关键帧与派生帧

时间轴采用「关键帧 + 派生帧」机制：只需要摆好关键姿势，中间画面自动计算。

1. 把播放头移到某一帧，点 `◆ 设关键帧` 或按 `K`，当前姿势被锁定为关键帧。
2. 移到另一帧，改变姿势，再打一颗关键帧。
3. 两颗关键帧之间会自动生成派生帧，不需要逐帧手动画。
4. 主轨按 `K` 只给真正发生变化的元件落关键帧；要精确控制某个元件，切到它的子轨再按 `K`。
5. 删除中间关键帧会合并前后段；删除首尾关键帧会让相邻姿势延续。
6. 复制关键帧得到的是新的关键帧，而不是普通帧。

### 5.3 段曲线与补间

- 点曲线下拉框可修改当前关键帧段的缓动方式，例如匀速、缓入、缓出、缓入缓出、自定义贝塞尔。
- 曲线只作用于当前元件当前段，不影响其他段或其他元件。
- 旧流程的 `补间` 仍然保留：先摆好首尾两帧，再选起始帧点补间，输入帧数即可。
- 支持分部缓动，可为位置、缩放、旋转、关节分别设置曲线。

### 5.4 高级设置

- **FPS**：调整每秒播放帧数。
- **洋葱皮**：半透明显示前后帧残影，方便校正动作。
- **全局属性修改**：开启后，对某个元件属性的修改会同步到该元件的所有帧；优先级高于 clip 整体调节与自动落帧。
- **帧缩略图**：在轨道长条上显示每格小图。
- **清空所有帧 / 清空非当前帧**：快速重置工程内容。

## 6. 轨道面板与 clip 元件

### 6.1 进入轨道模式

点时间轴控制栏的 `🎞 轨道` 切换视图：

- 每个元件占一行，出场的帧合并成一条长条。
- 轨道面板位于控制面板下方；展开控制面板时会叠在轨道之上。
- 再点一次 `🎞 轨道` 回到帧块视图，两种视图共用同一份工程数据。
- 手机端不会默认打开轨道模式，需要时手动开启。

### 6.2 clip 心智

轨道里的连续出场段可以理解成视频剪辑软件里的一个 clip：

- **无关键帧的 clip**：像一张图片占据一段时间。不开全局属性时，修改任意一帧都会同步到整段，不会自动打碎成关键帧。
- **有任意关键帧的 clip**：变成动画段。之后在其他帧修改该元件，会自动落关键帧。
- **全局属性修改**：优先级最高。开启后按全局属性规则处理，不受 clip 判定影响。
- **导入动作**：保持原样，不会因为导入就自动补满关键帧。
- **摄像机**：和普通元件一样支持 clip 整体调节；新建摄像机默认铺满总轨道长度。
- **删除 / 复制**：元件列表垃圾桶与轨道删除按钮会删除当前帧所在整段 clip；复制按钮会复制整段 clip，保留关键帧、曲线、分段信息和派生帧，只换名称和 ID。
- **分割**：只有点 `✂ 分割` 才会把当前段切成两段。

### 6.3 轨道基本操作

- **拉长 / 缩短**：拖动长条左右两端。拉长会复制边缘帧为普通帧，缩短会清掉腾空的帧。
- **整段平移**：按住长条中间拖动，不会挤进相邻长条。
- **点选**：点长条或轨道行会选中该元件；点空白处只移动播放头，不会取消当前选中。
- **眼睛按钮**：控制该元件全帧显示或隐藏。
- **播放头**：红色竖线表示当前帧，点轨道空白处可跳帧。
- **关键帧按钮**：菱形图标中间是 `＋` 表示可添加关键帧，是 `−` 表示当前帧已是关键帧。
- **关键帧拖动**：拖动白色菱形可移动关键帧；按住 `Alt` 拖动是复制。
- **关键帧多选**：`Ctrl / ⌘ / Shift` 点击可加选，双击可选中整条轨上的全部关键帧。
- **整组操作**：拖动已选中的关键帧可整组平移，`Alt` 拖动可整组复制。
- **复制关键帧 / 粘贴关键帧**：轨道控制栏的这两个按钮只复制 / 粘贴选中的关键帧，再到目标帧粘贴时会按复制时的相对间距铺开；帧面板的 `⧉ 复制帧` 才是复制当前普通帧。
- **循环**：选中一条 clip 后点 `⟳ 循环`，再拉长它时会按原段内容重复填充；关键帧与曲线按周期复刻。循环周期按开启时的原段保存，缩短只裁可见范围、不裁周期：例如 1–9 帧缩到 1–5 只显示前 5 帧，再拉长到 17 帧会显示 1–9 + 1–8。关闭循环后恢复为复制边缘帧。
- **编组循环**：循环对组整体生效；组外选中编组段开关循环，组内成员会按同一周期重复，进组后成员仍按原样编辑，不单独叠加成员循环。删除编组会连带组内成员一起删除。
- **框选**：在轨道空白处拖动可框选多条长条，支持整组平移、拉长 / 缩短和删除。
- **一次手势一步撤销**：拖动、框选、批量粘贴、批量删除都按一次操作记录。

### 6.4 轨道缩放

- **电脑**：把鼠标停在顶部蓝色刻度尺行上滚轮缩放。
- **手机 / 平板**：手指停在刻度尺行上双指捏合缩放。
- 在轨道面板下方滚轮仍然是上下滚动，不会误触缩放。
- 缩得很小时，刻度会显示为 `分:秒`。
- 放大时锚点固定在可视区左端，左侧内容不会被挤走。

### 6.5 音频轨道

- 音频轨永远在最底部。
- 长条显示占位声波，不显示画面缩略图。
- 音频轨可以移动、拉长、缩短、分割。
- 音频只在自身段落内出声，段外静音，不受 FPS 拖拽影响。

## 7. 媒体、蒙版与拖放导入

### 7.1 参考视频

- 参考视频用于对照动作，只显示在画布上作为参照。
- 它不进元件列表、不参与导出、不能被选择变换。
- 参考视频与「导入视频」是两种不同类型，图标和名称也分开显示。

### 7.2 蒙版与色度抠图

在「更多设置」里选中图片、图形、对话框、画笔或视频元件后，可打开 `蒙版`：

- **基础蒙版**：矩形 / 椭圆，支持水平位置、垂直位置、宽度、高度、羽化和反转。
- **色度抠图**：支持键控颜色、相似度、平滑度、色相容差、饱和容差、明度容差、溢出抑制、边缘羽化和只保留键控颜色。
- 基础蒙版与色度抠图上下排列，各自有独立开关，可以同时开启。
- 修改参数会按元件一起保存，参与预览和导出；音频元件没有蒙版入口。

### 7.3 拖放导入

可以把文件直接拖到 SKFE 窗口里，编辑器会自动识别：

- **图片**：作为图片 / 配饰导入。
- **视频**：作为视频元件导入。
- **音频**：作为音频元件导入。
- **JSON**：自动识别项目文件、动作文件或插件清单。
- **ZIP**：按插件包导入。
- 大文件导入前会提示确认；插件导入仍保留风险确认步骤。

## 8. 项目、动作与插件

### 8.1 项目库

- 在项目分区点 `导出并保存项目`，输入名字后会同时：
  - 下载同名 `.json` 工程文件；
  - 把工程保存到当前浏览器的项目库。
- 项目库会显示工程名称、帧数和 FPS。
- 点击项目库中的工程条目或打开按钮即可重新打开。
- 后台自动存档继续保留；清空画面请使用高级设置里的 `清空所有帧`。

### 8.2 项目与动作 FPS

- 项目文件会记录 FPS，项目库中也会显示。
- 保存 / 导出动作时会记录动作 FPS，动作库中会显示。
- 动作 FPS 只是元数据，不会自动覆盖当前工程里已经设置好的帧时长。

### 8.3 动作库

- 在高级设置里输入动作名称，可以把当前动作保存到动作库。
- 动作库中的动作可应用到其他火柴人身上。
- 导入动作会保留原有帧内容和关键帧信息，不会被自动改写。

### 8.4 插件

- 底部栏的插件入口用于管理本地插件。
- 支持按官方接口开发的数据型 / 代码型插件，也支持拖入 ZIP 插件包导入。
- 代码型插件会显示风险提示，确认后才加载。
- 安卓客户端点击「一键下载全部（ZIP）」会走原生保存 / 系统分享，不再依赖 WebView 的 `<a download>`。
- v8.0.0 起插件通过 `window.SKFE.api` 获得全开放能力：可读写工程数据、状态、DOM 界面、事件、媒体、编组、循环、撤销、导出、画笔、橡皮、摄像机、3D 模式与画布固定状态。API 版本为 `2.1.0`，旧接口保持兼容；MCP 插件可直接用 `api.mcp.call()` 调用全部稳定方法。
- 这是完全信任模型，没有沙箱；请只导入你信任的插件。
- 插件作者请阅读仓库里的 `插件API参考.md`；内部设计稿不随仓库发布。

## 9. 导出

导出面板按用途分组：**静态图片 / 视频 / 序列帧与动图 / 导出选项**。

### 9.1 静态图片与序列帧

- **PNG / JPG**：导出当前帧，可选择高清倍率。
- **PNG 序列**：把多帧打包成 ZIP。
- **SVG 序列**：只导出矢量内容，包括火柴人、内置形状、矢量画笔 / 橡皮擦结果；文字、位图、视频、发光、扭曲等非矢量内容不导出。
- 多选模式下可以只导出选中的帧。

### 9.2 GIF

- 可导出透明底 GIF。
- 支持高清倍率。
- 手机上导出后可按提示保存到相册。

### 9.3 视频

- **WebM**：支持透明底。
- **MP4**：兼容性更好，不支持透明底，可设置背景色。
- 两种视频都会把工程里的音频元件、视频元件音轨按段落混进导出文件；没有音轨时保持静音。音频按真实帧时长对齐，不受 FPS 拖拽影响。
- 部分设备没有 AAC 编码器时，MP4 会优先走浏览器录制以保留声音；若设备既不能编码 AAC 也不能录制带声 MP4，则只导出画面。
- 移动端如果高分辨率编码失败，编辑器会自动尝试较低档位；遇到编码提示时，可先关闭 1080p / 高倍高清，用较小尺寸重试。

### 9.4 导出选项

- 可设置导出范围、画布比例、背景色、透明底和画质。
- 有 2D 摄像机时，导出优先按 2D 摄像机取景范围处理。
- 3D 模式下，每一帧都按 3D 摄像机视角输出，镜头关键帧运动进入 PNG / JPG 序列、GIF、MP4 与 WebM；导出尺寸按 3D 摄像机画幅宽高计算。
- GIF 导出时地面网格线使用不透明绘制，避免 256 色量化把细线断成小块。
- 没有画布边界时，会按内容或默认比例计算取景。

## 10. 快捷键与常见问题

### 10.1 快捷键

| 按键 | 功能 |
| --- | --- |
| `C` | 复制当前选中物体 |
| `Delete` / `Backspace` | 删除当前选中物体 |
| `Space` | 播放 / 暂停动画 |
| `←` / `→` | 上一帧 / 下一帧 |
| `R` | 重置当前选中物体的姿势 |
| `Ctrl + Z` / `Cmd + Z` | 撤销 |
| `Ctrl + Y` / `Cmd + Shift + Z` | 恢复 |
| `Escape` | 关闭菜单或弹窗 |

### 10.2 常见问题

**页面刷新后看不到新功能？**

浏览器可能仍在用离线缓存的旧脚本。请强制刷新页面；仍不行时，在开发者工具里注销 Service Worker，或换无痕窗口打开。

**音频轨道为什么不是真实波形？**

当前显示的是确定性占位声波，用来表示段落和声音节奏，不是音频采样后的真实波形。

**视频 / 音频为什么只在一小段里响？**

视频元件和音频元件都只在自己的轨道段落覆盖的帧区间播放。请在轨道里检查段落范围、播放头位置和是否被静音 / 隐藏。

**项目文件很大，打开慢？**

带视频或音频的工程会把媒体数据写进 `.json`，文件可能很大。首次打开需要解码媒体，请耐心等待；不要手动编辑工程文件内部内容。

**安卓包升级提示签名冲突？**

旧安装包签名不同，需要先卸载旧版再安装。卸载会清掉 App 内存档，请先导出 `.json` 备份。
